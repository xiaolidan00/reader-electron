# Txt 阅读器 ReaderElectron与Web端

简单的 txt 阅读器，方便 pc 端摸鱼看或听小说，嘿嘿

访问地址：https://www.xiaolidan00.top/read/

## v1.0.0

- 导入 txt
- 批量操作，删除记录或文件
- 查看书本信息
- 搜索书架
- 看书分页，左右翻页，章节菜单栏
- 搜索内容关键词，跳转与高亮
- 语音阅读内容，速度，播音员
